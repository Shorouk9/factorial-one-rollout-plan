# Factorial One Rollout Plan

An independent proposal by Shorouk: a capacity-driven plan for moving Factorial's existing customers onto Factorial One, its AI agent platform, market by market.

**Live page:** https://shorouk9.github.io/factorial-one-rollout-plan/

## What's inside

- **Wave planner**: set the start date, team size, guided sessions per person per week and the share of customers who need a guided session; assign each market to a wave. Wave lengths, total weeks and the end date recalculate instantly.
- **Timeline**: prep, rollout and go/no-go gate for the pilot and each wave, drawn to scale by month.
- **Go/no-go gates**: enter adoption, answer accuracy, priority-1 incidents, satisfaction and support load to get Go, Hold or Roll back, with what to fix.
- **Risk log**: likelihood × impact scoring with a live risk grid.
- **Ownership (RACI)** by workstream.
- **AI project assistant** (when opened on claude.ai): writes the leadership status update, suggests missing risks and drafts wave announcements from the current plan.
